# Manual de uso da TechBairro

## A tela principal
Aparece o campo de nome,numero,email,endereço. E aparece os botões como salvar,cancelar e consultar.
nenhum cliente encontrado, cliente "nome do cliente " cadastrado com sucesso, Preencha o(s) campo(s),
cliente cadastrados:"e o numero", Cliente não encontrado: ele pode ter sido excluído. Nada foi alterado.
cliente atualizado com sucesso. 


## Cadastrar um cliente
1. Preencha os campos
2. E aperte o botão de salvar

## Consultar os clientes cadastrados
1. Aperte no botão de cadastrar

## Alterar os dados de um cliente
1. Aperte o botão de consultar e aperte em editar
2. clique em sim

## Excluir um cliente
1. Aperte no botão consultar
2. Seleciona o cliente 
3. Aperte no botão de excluir
4. E aperte em sim

## Regras de preenchimento
| Campo | Obrigatório? | Regra |
|---|---|---|
| Nome | sim | Não deixar o campo vazio e não prencher com numeros |
| Telefone | sim | não preencher com letras e não deixar o campo vazio |
| E-mail | sim | Deve conter o estilo de nome@gmail.com |
| Endereço | sim | Não preencher com letras os deixar o campo vazio |

## Mensagens do sistema
| Mensagem | O que significa | O que fazer |
|---|---|---|
| nenhum cliente encontrado | Que nenhum cliente foi encontrado | Preencher os campos de novo |
| cliente "nome do cliente " cadastrado com sucesso | Cliente foi cadastrado | abrir a consulta |
| Preencha o(s) campo(s) | Que deve preencher todos os campos |Preencher todos os campos corretamente |
| cliente cadastrados:"e o numero" | Que há clientes cadastrados | fechar e abrir a tela para ver se está cadastrado o cliente  |
| Cliente não encontrado: ele pode ter sido excluído | Que o sistema não encontrou nenhum cliente | preencher corretamente os campos e ver se o cliente vai ser cadastrado |
| Nada foi alterado | Qua apertou não na parte depois de confirmar a edição | Editar de novo e apertar em sim |
| cliente atualizado com sucesso | Que a edição foi feita | Confirmar se se a edição foi feita |
